# Imagens da LM Pudins

Esta pasta está reservada para os arquivos de imagem finais usados pela landing page.

Arquivos recomendados:
- `hero-pudim.webp`: fotografia principal, pudim claro com caramelo escorrendo.
- `pudim-frutas-vermelhas.webp`
- `pudim-laranja.webp`
- `pudim-chocolate-cafe.webp`
- `pudim-caldo-cana.webp`
- `pudim-maracuja.webp`
- `pudim-quatro-leites.webp`
- `pudim-romeu-julieta.webp`
- `logo-lm-pudins.png` ou versão SVG autorizada.

As fotos compartilhadas na conversa ainda não foram transferidas para este repositório. Até que os arquivos reais sejam adicionados, o layout usa ilustrações decorativas feitas com CSS como prévia visual, não fotografias dos produtos. Ao inserir imagens finais, atualizar os componentes para usá-las e manter texto alternativo acessível.
